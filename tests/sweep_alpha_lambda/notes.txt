========================================================================
 alpha x lambda sweep: seek-light and avoid-obstacles control demons
========================================================================

QUESTION
  The control demons learned slowly with alpha 0.03, lambda 0.3 (seek 1.4x random).
  Which step size alpha and trace decay lambda make them learn best, and which are unstable?

ANSWER
  alpha 0.1 with lambda 0 or 0.3 is best for both demons (alpha 0.3 is as good only at lambda 0).
  lambda >= 0.6 is unstable. Chosen: alpha 0.1, lambda 0.3 for both.

  Metrics       x random  = learned reward/step / random reward/step

                bumps     = bumps per 1000 steps

------------------------------------------------------------------------
CONCLUSIONS
------------------------------------------------------------------------
  - Raising alpha from 0.03 to 0.1 more than triples seek (1.37x -> 4.53x) and lifts avoid (1.53x -> 1.74x).
  - lambda >= 0.6 diverged (max|theta| overflow / nan in the .txt logs) for most alphas;
    lambda 0.9 diverged at every alpha.
  - Identical scores across seeds (seek 0.24x, avoid -1.74x, 983.9 bumps/1k) look like a diverged demon
    stuck on one action [inference: not checked against the weights].
  - seek's best settings peak at 500-750k, then drop, and differ a lot between seeds (3.02 - 6.57x).
  - Decision: alpha 0.1, lambda 0.3 for both demons. The reason for picking it over alpha 0.3, lambda 0
    is not recorded. [inference: one setting works for both demons, seek bumps less (247 vs 385/1k),
    and alpha 0.3 is unstable as soon as lambda > 0.]

CAVEATS
  - Only 1M steps from zero weights. In the long Horde run, alpha 0.1 diverged when switched on at 7.825M
    from warm weights (tests/horde_diverged_alpha01); the min(1, rho) trace cap fixed it
    (tests/horde_12M_capped_trace).
  - Only 3 seeds; seek varies a lot between them.

WHAT IT LED TO
  - alpha 0.1, lambda 0.3 used from 7.825M in the long run and from step 0 in tests/final_offpolicy_vs_onpolicy.

------------------------------------------------------------------------
HOW TO REPRODUCE
------------------------------------------------------------------------
  Check out commit 9e00452 and apply the brightness / FL+FR reward change, then from a folder inside the repo:
      PYTHONPATH=.. python3 -u sweep.py seek 0      (demon name prefix, seed)
  for seek and avoid, seeds 0, 1, 2.

FILES
------------------------------------------------------------------------
  sweep.py                    the sweep script
  sweep_<demon>_<seed>.npz    results (4 evals x 17 rows (16 copies + random) x [reward/step, reached %, bumps/1k])
                              and grid (16 x [alpha, lambda]). Use these for numbers.
  sweep_<demon>_<seed>.txt    printed logs. The max|theta| column overflows for diverged copies and merges
                              with bumps/1k, so do not parse it.
