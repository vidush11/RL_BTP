 Horde run 9.0M - 10.9M: avoid-obstacles diverged again -> rho capped in the trace
========================================================================

QUESTION
  After the alpha 0.1 divergence at 9.0M (tests/horde_diverged_alpha01), seek-light and avoid-obstacles
  were reset to zero weights. Does alpha 0.1 stay stable from a fresh start inside the long run?

ANSWER
  No. Both learned well for ~1.7M steps, then avoid diverged at ~10.775M. Cause: uncapped importance
  ratio rho in the trace. Fix: rho capped at 1 in the trace, used in every run since.

------------------------------------------------------------------------
CONCLUSIONS
------------------------------------------------------------------------
  - alpha 0.1 learns much better than 0.03 (seek 3-6x vs ~1.2x before), but is not stable with uncapped rho.
  - Divergence was sudden: avoid weights grew slowly for 1.6M steps, then jumped 2.5 -> 40 in ~100k steps.
  - [inference, from the horde.py comment written with the fix] a rare behaviour action the target likes
    has rho ~25, which multiplied the trace by ~7 and blew up the weights.

WHAT IT LED TO
  - Fix A at 10.9M: rho capped at 1 in the trace, e = phi + gamma*lambda*min(1, rho)*e (horde.py lines 92-96,
    in commit 864ad85); seek and avoid reset again; eval switched to 100 fresh starts per eval shared by all
    control demons (tests/horde_12M_capped_trace/train_log.txt line 6188).
  - With the cap the run stayed stable to 11.95M (tests/horde_12M_capped_trace); the final run uses it from step 0.

CAVEATS
  - Evals use 50 starts, so single evals are noisy (seek jumps 1.5x - 9x between evals).
